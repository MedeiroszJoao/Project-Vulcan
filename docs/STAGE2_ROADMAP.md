# Research extensions AFTER prospective release

Freeze prospectivity first; do not let attractive enhancements delay the first publicly registered flight-conditional Y forecast.

## 1. EVPPI — identify highest-value uncertainties

For a legitimate joint distribution over uncertain quantities X, compute `EVPPI_X = min_a E[C(a)] - E_X[min_a E[C(a)|X]]` (nonnegative for finite feasible actions, with the same action set). Use it only for model-defined epistemic parameters that actually have defensible scenario distributions. A grid of 360 unweighted structural cases has NO unique EVPPI without adding a new normative probability measure. Test EVPPI=0 if parameter irrelevant to outcomes/decision and EVPPI<=EVPI for a common feasible action set. Keep the net cost of waiting distinct from pure value of perfect partial information. Report near-nonidentifiability rather than force numerical certainty.

## 2. Hierarchical pooling by revision and lot

Prototype `p_j ~ Beta(alpha,beta)` at revision/lot j with coherent hyperpriors, explicit observation model and known identifiers only. Use `p_j` to share information rather than treating Atlas GEM63 and Vulcan GEM63XL as equal exposures. **Block** actual posterior estimation until corresponding flight IDs/hardware revisions/lots and reporting mechanisms can be linked to sources. Otherwise run only synthetic-identifiability tests. Evaluate partial-pooling bias with controlled synthetic ground truths and leave-one-group-out validation. Avoid claiming an empirical correction-effect posterior on undocumented revisions.

## 3. Minimal physical event tree (before operating advice)

Define physical fault occurrence → thrust/separation effect → guidance compensation → achieved orbit class → mission loss / degradation; include competing independent causes and launch config. Elicit probability intervals from domain practitioners, clearly mark nonpublic unknowns. Ensure common cause model represents real conditional dependence rather than an abstract ρ stress alone. This becomes a new model version, not an after-the-fact reinterpretation of the prospectively registered episode 1.

## 4. Longitudinal series / retrodiction

For each subsequent publicly reportable six-booster or other SRB flight, register a new forecast target, hardware definition, publicly ascertainable categories, and issue cutoff before flight. Do not combine uncalibrated signals across fundamentally different missions as if exchangeable. Backtest with archival public-availability timestamps (not current pages) on Vega-C and GPS III-8 only as illustrative decision comparisons. Record differences between available public and private information as limitations.
